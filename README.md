#  AI ChatBot using Python

##  Project Overview

This is a simple AI ChatBot developed using Python.
It can:

- Greet users
- Tell the current date and time
- Perform basic calculations
- Tell jokes
- Open YouTube, Google, and GitHub
- Remember the user's name

##  Technologies Used

- Python
- datetime
- webbrowser

##  How to Run

1. Install Python 3.
2. Download the project.
3. Open terminal.
4. Run:

```bash
python chatbot.py
```

##  Sample Output

You: hello
Bot: Hello! Nice to meet you.

You: time
Bot: Current time is 08:00 PM

You: bye
Bot: Goodbye!
